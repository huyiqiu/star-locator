# 手持棋盘格实时标定

## 操作步骤

1. 在工作台左侧选择“相机标定”。可直接复用实时取景里已连接的后端 USB 相机，也可在标定页设置设备索引与分辨率后连接。
2. 输入棋盘的横向内角点数、纵向内角点数和**实际测量的**方格边长。9×6 内角点对应 10×7 个黑白方格；系统可下载按毫米尺寸生成的 SVG。
3. 设置目标视图数量，默认 20，允许 8–50。建议使用至少 15–25 个视角。
4. 将完整棋盘放入预览。点击“开始自动采集”，手持棋盘缓慢变换位置、距离和倾角，每次短暂停稳约半秒。角点检测为独立算法，不依赖反光点阈值参数。
5. 先拍中间，再移动到画面四角，分别向上、下、左、右倾斜。只平移或绕画面旋转棋盘，不能代替改变板面倾角。页面会显示有效视图数、角点数、稳定状态和区域覆盖，重复视角不会增加计数。
6. 达到目标后自动暂停采集并计算内参，右侧显示整体与每视图重投影误差。如果提示倾角或边缘覆盖不足，可提高目标数量、继续补拍，再重新计算。
7. 检查结果后点击“应用标定结果”。计算预览不会直接覆盖已有内参；应用后，后续星阵图像才使用新内参计算物理位姿。

可以随时暂停自动采集，或使用“手动采集这一帧”。上传照片仍可用于补充同一规格、同一分辨率的标定视图。离开标定页会暂停自动采集；返回后可继续，已采集的数据保留到本次服务重启或主动清空为止。

刷新或重新进入页面时，已有视图对应的棋盘规格与分辨率会自动恢复；修改目标视图数量会保留已有区域覆盖统计。相机停止时，仍可计算已采集视图的内参。

## 质量检查

- 棋盘应平整，保持固定焦距，采用真实工作时的红外模式、分辨率和裁切。
- 自动采集检查完整角点、成像尺寸、图像边距、清晰度、短时稳定和与已有视角的差异；这些是采集筛选条件，不是定位精度保证。
- 3×3 区域覆盖统计来自实际观察到的角点。倾角多样性根据透视边长比例变化估计，仅作采集指导；不输出未经标定的真实倾角。
- 红外下普通打印墨水不一定有充分黑白对比。若一直提示“等待完整棋盘”，请先检查实际红外图像中的棋盘对比与过曝情况。
- 修改棋盘规格或取景分辨率后，需要清空旧视图。清空动作带会话版本校验，检测中的旧帧不会在重置后重新加入。

## 接口

`POST /api/calibration/observe` 复用已经连接的后端 USB 相机，无需重复上传同一帧：

```json
{
  "columns": 9,
  "rows": 6,
  "square_mm": 25,
  "collect": true,
  "target_views": 20,
  "session_revision": 1
}
```

首次可从 `GET /api/calibration/status` 获取 `revision`。使用 `collect:false` 只做实时检测和反馈，不保存视图。响应包括 `found`、`stable`、`accepted`、`reason`、`message`、`corners_px`、`views`、`coverage`、`target_reached` 以及带角点的预览图。

自动采集通常先返回 `hold_still`，约半秒后的新鲜、稳定观察才返回 `accepted`。同一视角会返回 `duplicate`。没有棋盘时返回正常反馈 `board_not_found`；没有新鲜相机图像时返回 HTTP 409。

`POST /api/calibration/solve` 返回待检查的内参、每视图误差、覆盖与质量提示；`PUT /api/intrinsics` 才保存应用。
