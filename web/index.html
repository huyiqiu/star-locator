标记基准族.

十八种图案，统一尺度。每个 ID 都有唯一可识别的方向。

单帧检测

multipart/form-data 上传图像，可同时传入内参与检测参数；接口无状态，不读取服务端保存值。默认不返回画面，适合机器人直接读取结果。

POST/api/v1/detect

返回字段

id / direction_deg标记 ID / 图像内顺时针方向
T_camera_marker板坐标 → 相机坐标；矩阵平移为 mm
T_marker_camera相机坐标 → 板坐标；矩阵平移为 mm
tvec_mm / tvec_cm标记原点在相机坐标系的位置（marker-in-camera）
camera_position_marker_cm相机光心在标记坐标系的位置（camera-in-marker）
distance_cm标记中心到相机光心的直线距离
pose.filtered仅实时视频：平滑后的位姿，同时提供厘米字段
ambiguous平面双解尚无法可靠区分
quality_score几何评分，非概率或协方差
